# 弈步 0.9.1 安装包

[打开 APK 下载页面](https://github.com/well49112/yibu-chess/blob/apk-downloads/yibu-0.9.1-arm64.apk)

手机浏览器先登录 GitHub 账号 `well49112`，进入页面后点击 **Download raw file** 下载。约 22.4 MiB，支持 Xiaomi 17 Pro 等 ARM64 手机，最低 Android 8.0。Maia 模型与音效内置；Stockfish 分析和最强对手需要联网。

本版改动：

- 修复重复打开个人弱点例子的闪退。已在旧版本代码中复现异常，路线、注释与走法名称现在统一使用同一份合法变化；有效讲解直接复用缓存，再次打开回到起点。
- “棋谱”顶部加入错题练习，从最近 20 盘保留棋谱的已确认战术失误出题，每轮最多 10 题。先隐藏答案，用棋盘作答，支持白黑视角、升变、两级提示和答案揭示。
- 独立答对与辅助完成分开记录，安排间隔复习。完成后可进入实战/推荐对照讲解，再返回本轮继续；进度保存在手机，练习不改变原棋谱或 Elo，也不新增云端请求。
- 恢复底部“整盘深度复评”：deep 重新分析双方每一着，包括已有极速或深入缓存的棋步。上方全局复盘仍用于玩家关键点。失败时保留已完成结果，明确显示未完成。

已有同深度、评分接近的第二候选也可作为练习答案。其他新走法只提示未匹配，不声称一定错误。题目只覆盖有证据的基础战术失误，没有题目不代表没有失误。

同包名、同签名，versionCode 为 19，可覆盖安装，保留棋谱、个人 Elo、口令与设置，不迁移数据库。两个对手、后台极速分析、音效与 1–2 秒模拟思考沿用原有行为。

23 项相关检查通过，原签名 release APK 构建完成。仅验证此次新增和直接受影响的行为，未运行全量回归或全量 lint，未在 Xiaomi 真机或生产服务重新验证；上传后不重复下载验证。
