# 弈步 1.0.2 安装包

[打开 APK 下载页面](https://github.com/well49112/yibu-chess/blob/apk-downloads/yibu-1.0.2-arm64.apk)

手机浏览器先登录 GitHub，进入页面后点击 **Download raw file** 下载。约 22.5 MiB，支持 Xiaomi 17 Pro 等 ARM64 手机，最低 Android 8.0。Maia、开局课程与音效内置；Chess.com 导入和 Stockfish 分析需要联网。

本版改动：

- 教学改为互动小课：看一个目标，亲手在棋盘上走出来，完成后解释原因，点击继续再看对手回应。没有自动播放。
- 提供两级提示和示范，需要帮助的目标会在课末再练一遍；合法但未匹配课程路线的走法不被判为坏棋。
- 教学棋盘与对弈棋盘同宽，小屏使用滚动展示完整解释；主要操作固定可见。逐步讲解、自由试走和不计分陪练保留在更多。
- 10 套开局每套 4 条路线，共 40 条。新增埃文斯、斯拉夫、俄罗斯防御、潘诺夫、封闭西西里、莫拉等常见分支，按名称选择，保留旧学习记录。

小米手机若限制后台运行，可在“后台运行设置”将省电策略设为无限制，并允许后台自启动。通知权限只在主动点击时请求，不授权也能启动服务。系统强行停止、重启或资源限制可能中断服务，已完成结果会保留，下次打开继续。Android 15 及以上限制此类服务后台累计 6 小时 / 24 小时，达到时限会保存并停止，打开 App 后继续。

同包名、同个人签名，versionCode 23，可覆盖安装并保留棋谱、课程/练习记录、个人 Elo、口令与设置，无数据库迁移。保留 Chess.com 批量导入和 1.0.1 的全部棋谱自动分析/后台服务。

20 项针对性检查通过，构建原签名 release APK。只验证此次新增和直接受影响的行为，未运行全量回归或全量 lint；Cloud 未在 Xiaomi 真机测试，上传后不重复下载验证。
