# 弈步 0.9.0 安装包

[打开 APK 下载页面](https://github.com/well49112/yibu-chess/blob/apk-downloads/yibu-0.9.0-arm64.apk)

手机浏览器先登录 GitHub 账号 `well49112`，进入页面后点击 **Download raw file** 下载。约 22.3 MiB，支持 Xiaomi 17 Pro 等 ARM64 手机，最低 Android 8.0。Maia 模型与音效内置；Stockfish 分析和最强对手需要联网。

本版改动：

- 移除复盘底部重复的“整盘深度复评”按钮，保留顶部全局关键点入口与单步复评。
- 单步讲解和关键点都支持实战线 / 推荐线切换，从同一个落子前局面手动演示。每着有注释，高亮刚走的一着，箭头提示下一着应对；两条路线各最多 16 着，缺少合法后续时明确说明，不编造招数。
- “棋谱”页顶部提供个人弱点统计：最近 20 盘保留的已结束对局，只统计自己的已确认战术问题，展示分析覆盖率、发生次数与涉及局数、具体例子和下一阶段小目标。
- 支持漏防将杀、漏看直接丢子、错过将杀、错过双攻赢子和错过直接赢子。普通等价交换、合理好棋和只有分差的棋步不贴标签；没有标签不代表没有失误。
- 点击统计例子打开对应棋步的对照讲解，不追加云端请求。统计在本机后台计算，复用未变化棋谱，删除后移除证据，复评后更新。旧讲解使用保存的分析本地升级，不迁移数据库。

实战线后续是原落子后的引擎参考应对，不是之后实际下出的棋谱；推荐线也只是参考变化。切换路线回到同一起点，不改变原对局与 Elo。

同包名、同签名，versionCode 为 18，可直接覆盖安装，保留棋谱、个人 Elo、口令与设置。后台极速模式、分析耗时导出、1–2 秒 AI 模拟思考、音效、两个对手与默认随机白黑沿用原有行为。
