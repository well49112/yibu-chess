# 弈步 0.9.2 安装包

[打开 APK 下载页面](https://github.com/well49112/yibu-chess/blob/apk-downloads/yibu-0.9.2-arm64.apk)

手机浏览器先登录 GitHub 账号 `well49112`，进入页面后点击 **Download raw file** 下载。约 22.4 MiB，支持 Xiaomi 17 Pro 等 ARM64 手机，最低 Android 8.0。Maia 模型与音效内置；Stockfish 分析和最强对手需要联网。

本版改动：

- “整盘深度复评”改用 lightning：目标深度 22、500ms 搜索预算、MultiPV=2。继续重新分析双方每一着，包括已有缓存；失败或暂停保留已完成结果。单步复评、全局关键点缺失分析与讲解缺失分析也使用 lightning。
- 错题题面显示你当时的错误走法，包括棋步名称、棋子与起止格，推荐答案仍隐藏。
- 答对或查看答案后，当前界面直接讲解原走法的具体后果，以及答案怎样保住棋子、兑现双攻、赢子、将杀或解将；附后续参考应对。净子力按双方实际吃子和升变计算，不用评分差替代原因。
- 接受评分接近的第二候选时，使用你实际选择的那条变化讲解。仍可进入棋盘对照；题目、间隔复习和解释在本机处理，不新增云端搜索。

500ms 是搜索预算，网络和服务器排队另计，复杂局面不保证达到 22 层。已有合格旧缓存可以直接用于关键点和讲解；整盘按钮会重新分析双方全盘。

同包名、同个人签名，versionCode 为 20，可覆盖安装，保留棋谱、练习记录、个人 Elo、口令与设置，无数据库迁移。两个对手、后台档位和模拟思考沿用原有设置。

26 项相关检查通过，构建原签名 release APK。仅验证此次新增和直接受影响的行为，未运行全量回归或全量 lint；Cloud 未在 Xiaomi 真机或生产服务重新验证，上传后不重复下载验证。
