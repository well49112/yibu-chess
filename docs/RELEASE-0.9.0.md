## 两条路线对照

单步讲解与关键点都可以切换“实战线 / 推荐线”，从同一个落子前局面开始。实战线展示原落子后的引擎应对，推荐线展示改走推荐后的参考应对；后续都不是整盘实战棋谱的重放。切换时回到起点，不改变原棋谱、结局或 Elo。

关键点按手动“下一步”先查看实战应对，再回到起点查看推荐；也能直接按路线按钮切换。两条路线各最多 16 着，每着有中文注释；高亮刚走的一着，箭头提示下一着参考应对。棋盘和按钮固定，说明可以独立滚动。第一着相同时说明“首着一致”。缺少合法实战后续时只显示原落子，明确指出缺少应对，不使用推荐变化冒充实战线。将杀、非法后缀或短变化会提前停止，不凑长度，不自动播放。

讲解版本升到 5，新增的实战变化和注释采用兼容的可选字段存到原棋谱；旧讲解用已保存分析本地升级，不重复请求引擎，不迁移数据库。

## 个人弱点

入口位于“棋谱”页顶部。只统计最近 20 盘保留的已结束对局，包括匹配与最强对局；只选择玩家自己的有效同深度分析，显示已确认分析棋步数 / 玩家总棋步数及有分析的局数。统计使用保留棋谱，不声称覆盖全部历史，也不把没有标签当成没有失误。

| 类型 | 所需证据 |
| --- | --- |
| 漏防将杀 | 实战评估为本方被将杀，合法变化实际到达对手将杀，推荐没有相同被将杀评价 |
| 漏看直接丢子 | 对手第一着吃掉轻子、车或后，本方无法立即合法回吃，实际净子力减少，推荐前两着更好 |
| 错过将杀 | 推荐评估有将杀，合法变化实际到达本方将杀，实战未保留将杀评价 |
| 错过双攻赢子 | 推荐同时攻击至少两个有价值目标或王，随后由该棋子实际吃到目标，计入双方交换后有净收益 |
| 错过直接赢子 | 推荐第一着吃掉轻子、车或后，计入双方交换后仍有至少轻子价值的净收益，实战收益更少 |

除覆盖率外，每着最多归入一类，需评级为已确认的不精确或失误、期望得分损失至少 4 个百分点，推荐与实战不同。待确认、旧评级算法、深度不匹配、非法首着、只有分差及合理好棋不归类；普通等价交换不会因被回吃就被记为丢子。将杀证据必须在最多 16 着合法变化内实际到达；较长或未完整显示的战术可能暂不归类。

每类展示次数和涉及局数、最多三个最近例子及证据，样本仅来自一局时说明样本有限。点击例子打开对应棋步的对照讲解，使用已有分析，不追加云端请求。最常出现的类别给出接下来三局的简单检查目标。统计在后台本地计算，复用未变化的棋谱，删除后移除证据，复评后更新；不改变个人 Elo。

沿用包名 `cn.yibu.chess` 和个人签名，versionCode 18；覆盖安装保留棋谱、Elo、口令与设置。内置 Maia、两个对手、随机白黑、1–2 秒模拟思考、音效、后台极速参数及耗时导出沿用原有行为。
