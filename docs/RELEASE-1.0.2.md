## 先走出来，再理解原因

开局课程默认进入互动教学。每课练你所执一方的走法：看一个目标，在棋盘上作答，完成后立刻解释具体保护的子、控制的格、吃回的兵、易位和当前威胁。对手回应与下一目标仅在点击“继续”时推进，保持手动节奏。

没有匹配课程答案的合法走法留在原局面，说明本关目标并允许重试，不给它贴坏棋评级。两级提示先提供方向，再给走法与箭头；“看示范”也可以完成当前目标。未匹配、提示过和示范过的目标在课末集中再练一遍，不反复循环阻止结课。总结区分首次独立完成与辅助完成，并给出该路线重点、最后局面说明和要注意的风险。

完成记录保存在本机，旧主线/分支学习与练习键保留。辅助完成计入学习，所有目标首次作答成功且未使用提示/示范时才额外记为独立练习完成。教学不改变当前棋局、棋谱、个人 Elo 或错题统计，不发起引擎分析请求。原逐步讲解、自由试走、Maia 回应与从当前位置不计分陪练保留在“更多”。

## 大棋盘与简化操作

去掉原有页面高度 36% 和 300dp 上限，教学使用对弈页同样的内容宽度、1:1 棋盘和边框。小屏通过滚动展示教学内容，不压缩棋盘。答后解释和提示进入可见区域，主要动作固定可见；棋子选择在历史、模式或路线改变时重置，防止第二步失去响应。

路线通过名称选择，每套四条，不再多个按钮都叫“常见分支”。课程列表按实际数量显示进度；路线选择显示旧学习记录及互动完成状态。
