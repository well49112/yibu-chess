## Chess.com 批量导入

棋谱页右上角“导入”使用 Chess.com 公开棋谱 API。输入用户名后在本机记住，下次自动填入；可选择最近 30 盘、100 盘或全部历史，不需要密码，也不发送 Stockfish 口令。按月份从新到旧请求并保存，每个月写入后才读取下个月。停止或后续请求失败时保留已保存棋局，重试自动跳过已有棋局。

只导入已结束、标准起始局面的标准国际象棋。解析主线 SAN，支持时钟注释、附着的棋步编号、易位、升变、吃过路兵、变化和 NAG；完整校验合法性，拒绝不完整、非法或结果不一致的棋谱。变体和无法解析的棋局跳过并计数；不保存半份棋局。

原用户名、执白/执黑、双方 Chess.com 分数、结果、用时类别、来源 URL 和完整原 PGN 保存在棋谱。ID 来自来源 URL，重复导入保留原有分析与讲解；已删除棋局不会重新出现。导入不改变个人 Elo，不影响当前对局。可用原有远端 lightning 复评、关键点与逐步讲解；确认过的本人失误可以进入个人弱点和错题练习。导出 PGN 保留原文。

## 10 套离线开局课程

| 执棋 | 课程 |
| --- | --- |
| 白 | 意大利、西班牙、苏格兰、伦敦、后翼弃兵 |
| 黑 | 双王兵、卡罗康、法兰西、西西里、后兵稳固防守 |

每套提供一条主线与一种常见分支，共 20 条参考路线。主线展示 16 个半回合，分支各展示 12 个半回合。说明按实际棋盘逐着编写，解释具体保护的兵、攻击的目标、退路、易位、中心推进及下一阶段安排；只在手动操作时前进，没有自动播放。

分支练习把参考答案隐藏，点击棋盘作答；可查看提示，答对后在同屏显示具体原因。其他合法走法不匹配本题教学目标时不自动判为坏棋。自由试走可替双方落子、撤回，也可让离线 Maia 回应一着。轮到对手时采用原有 1–2 秒模拟思考；切路线、返回、切后台取消旧回应。

“从这里陪练”保留当前完整走法历史与课程执棋颜色，启动与个人棋力匹配的 Maia 对局，不计 Elo。课程预置走法不纳入本人关键点、弱点或错题，只有之后自己走的棋计入；对弈后台不重复搜索课程预置步骤。学习和答题进度本地保存。

课程可匹配已导入的相同颜色、相同开局前缀的实战，跳到开始不同的局面进行复盘。只识别这 20 条参考路线，未匹配、偏离课程或走法转置不自动意味着失误。

## 界面整理

底部加入“训练”，内部为“开局课程 / 我的训练”。个人弱点与错题入口移到我的训练；开局课程按执白/执黑筛选，每组 5 套。

棋谱页聚焦导入、筛选、打开和删除，顶部不再堆叠弱点与错题卡片。导入表单通过右上角按钮打开，进行中的进度与结果显示在可收起的状态条。棋局按全部 / Chess.com / 本地对弈 / 开局陪练筛选。
